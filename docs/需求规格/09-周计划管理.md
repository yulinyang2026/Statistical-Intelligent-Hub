# 09 周计划管理

## 1. 模块定位

### 1.1 职责

周粒度的计划编排：任务池、本周计划（周一~周日）、本周实际（周一~周日）三区块；拖拽编排并**写回任务计划完成日期**；标记完成、填写实际工时、当天新建任务；计划与实际对照。

### 1.2 边界

- **月计划已移除**（V5.0），不再提供周/月页签切换。原月计划需求 **FR-PLAN-007 / FR-PLAN-008 已作废**。
- 不负责任务的创建与编辑（跳转 `08-任务管理.md`），但「当天新建」在本模块内发起。

> 周计划于 V5.0 重构（**FR-V5-004**：去月计划页签、周切换控件、任务池改为当月全部任务、拖拽写回 planDate、实际区支持标记完成/填工时/当天新建），于 V5.1 修复（**FR-V5-021**）。第 4 节表格为合并后的现行口径。
- 任务池为**读取任务数据**，不是独立实体。

## 2. 依赖关系

| 方向     | 对象                                                                |
| -------- | ------------------------------------------------------------------- |
| 依赖     | `08-任务管理`（任务数据与 planDate 写回）、`12-用户与组织`（人员）   |
| 被依赖   | 无（终端应用）                                                      |
| 数据实体 | PlanItem（主）、Task（引用并写回 `planDate`）、User                  |

## 3. 数据契约

**主实体 PlanItem**

| 字段     | 类型   | 必填 | 说明                                          |
| -------- | ------ | :--: | --------------------------------------------- |
| id       | string |  —   | 主键，前缀 `pi`                               |
| taskId   | string |  √  | 关联任务                                      |
| granularity | string | √ | 粒度，**当前仅使用 `week`**（月已停用）    |
| periodKey | string | √ | 周期键，如 `2026-W37`                        |
| day      | number |  —   | 星期（1~7），月粒度时为空                     |
| type     | string |  √  | `计划` / `实际`                               |
| hours    | number |  —   | **实际工时**（可空，实际任务填写）            |
| createdBy | string | —  | 填写人                                        |
| createdAt | string | —  | 填写时间                                      |

**写回规则**：拖拽任务到本周某天 → 写回该任务的 `planDate` 为该天日期；同一任务拖到多天时，取**未来最远一天**。

## 4. 功能需求

| 编号        | 需求描述                                                                                                                                                             | 优先级 |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :----: |
| FR-PLAN-001 | 三区块：**任务池**、**本周计划任务（周一~周日）**、**本周实际任务（周一~周日）**；顶部**切换周的周控件**，可查看历史与未来周                                            |   P0   |
| FR-PLAN-002 | **任务池**：**截止月份 = 当前查看周所在月**的全部任务（**含已完成**，已完成置灰且不可拖动）；显示任务名称、执行人、优先级、截止月份、预计工时、归属                    |   P0   |
| FR-V5-021   | 修复与口径固化：① 周切换控件可正常切换周期；② 任务池口径如上；③ 本周实际区「当天新建」支持选择执行人（自动带出，异常时回退当前用户）                                   |   P0   |
| FR-PLAN-003 | **拖拽编排**：任务池任务拖到本周计划具体星期；支持重复拖动（可安排多天，多天各计一次预计工时）；支持星期间移动与移回任务池；**拖拽后写回任务 planDate**（多天取最远）    |   P0   |
| FR-PLAN-004 | **填写实际**：每天填写本周实际任务；若任务属本周计划，可标记完成 → 任务状态更新为「已完成」并从任务池消失；支持**填写实际工时**与**当天新建任务**（计入实际）           |   P0   |
| FR-PLAN-005 | 周汇总：本周计划工时合计、本周实际工时/任务数合计，计划与实际对照                                                                                                          |   P1   |
| FR-PLAN-006 | 替下属编排：部门经理/组长可在权限范围内切换查看/编排下属的周计划                                                                                                            |   P1   |

## 5. 接口清单

| 方法   | 路径                    | 说明                                                                          | 所需权限点 |
| ------ | ----------------------- | ----------------------------------------------------------------------------- | ---------- |
| GET    | `/api/plans`            | 周计划数据，参数 `granularity=week`、`key=2026-W37`、`month=2026-09`；返回 `{ pool, planWeek, actualWeek, summary }` | `plan.view` |
| GET    | `/api/plans/people`     | 可编排人员列表（本人 + 下属，用于替下属编排与执行人下拉）                      | `plan.view` |
| POST   | `/api/plans/items`      | 新增计划项（拖拽落位），写回任务 `planDate`                                    | `plan.edit` |
| PATCH  | `/api/plans/items/:id`  | 修改计划项（星期移动、实际工时）                                              | `plan.edit` |
| DELETE | `/api/plans/items/:id`  | 删除计划项（移回任务池）                                                      | `plan.edit` |
| POST   | `/api/plans/complete`   | 标记任务完成（任务状态 → 已完成，从任务池消失）                                | `plan.edit` |

## 7. 验收标准

- [ ] **无月计划页签**，仅有周粒度视图
- [ ] 周切换控件可切换到上一周/下一周并正确刷新
- [ ] 任务池展示截止月份 = 当前周所在月的全部任务，含已完成任务
- [ ] 已完成任务在任务池置灰且不可拖动
- [ ] 拖拽任务到某天后，该任务的「计划完成日期」更新为该天日期
- [ ] 同一任务拖到多天时，planDate 取未来最远一天
- [ ] 从星期移回任务池，计划项删除
- [ ] 标记完成后任务状态变「已完成」并从任务池消失
- [ ] 实际区可填写实际工时、可当天新建任务且执行人可选
- [ ] 部门经理/组长可切换查看下属周计划
- [ ] 周汇总的计划工时与实际工时计算正确
