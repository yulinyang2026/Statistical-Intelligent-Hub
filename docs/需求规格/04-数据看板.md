# 04 数据看板

## 1. 模块定位

### 1.1 职责

登录后首页，提供**只读聚合视图**：统计卡片、我的待办（近三天）、任务完成情况、三类未完成任务分布图。

### 1.2 边界

- **只读**，不提供任何写操作（写操作跳转对应模块）。
- 不负责具体对象的增删改（见 05/06/07/08）。
- 已下线区块（V5.3）：项目状态分布环形图、各归属产品项目分布、最新动态时间线、底部待办大表格。

## 2. 依赖关系

| 方向     | 对象                                                                       |
| -------- | -------------------------------------------------------------------------- |
| 依赖     | `08-任务管理`、`07-项目管理`、`05-模块管理`、`06-专题管理`、`12-用户与组织` |
| 被依赖   | 无（终端展示模块）                                                         |
| 数据实体 | Task、Project、Module、Topic、User                                         |

## 3. 数据契约

| 字段                  | 说明                                                                        |
| --------------------- | --------------------------------------------------------------------------- |
| `cards`               | 统计卡片数值：moduleCount / topicCount / projectCount / buildingCount / taskTotal / taskDone / taskRate / myTodoCount / scopeNote |
| `taskStatusDist`      | `[{ name, value }]`，四状态任务数                                           |
| `myTodoRange`         | `{ from, to }`，近三天日期区间（本地日期）                                  |
| `myTodo[]`            | 近三天待办任务列表（含 `belongLabel`、`subsystemName`、`canEdit`）          |
| `projectTaskDist[]`   | 各项目未完成任务分布：`{ id, name, 待处理, 进行中, 受阻, total }`           |
| `moduleTaskDist[]`    | 各模块，字段同上                                                            |
| `topicTaskDist[]`     | 各专题，字段同上                                                            |

## 6. 权限要求

| 角色       | 查看看板 | 数据范围                     |
| ---------- | :------: | ---------------------------- |
| 系统管理员 |    √    | 全部数据                     |
| 部门经理   |    √    | 权限人员（本人 + 所辖组长及组员） |
| 组长       |    √    | 权限人员（本人 + 本组组员）  |
| 组员       |    √    | 仅本人参与 / 分配给自己的    |
| 只读查看者 |    √    | 全部数据（只读）             |

## 7. 验收标准

- [ ] 统计卡片数字与对应列表页统计一致（口径相同）
- [ ] 「我的待办」只含近三天且分配给当前用户的未完成任务
- [ ] `planDate` 为空但 `deadline ≤ 当前月` 的任务出现在我的待办（兜底生效）
- [ ] 三个分布图只统计未完成（待处理/进行中/受阻），**不含已完成**
- [ ] 分布图最多 10 根柱，按未完成任务数降序
- [ ] 切换角色后，所有数字与分布图随之变化（权限过滤生效）
- [ ] 模块/专题分布图数字与对应列表页「待办任务」列一致（含挂靠项目任务）
- [ ] 近三天日期区间显示正确，跨月不出现时区偏移
