# 17 AI 智能助手（管理小帮手）

## 1. 模块定位

### 1.1 职责

系统级「管理小帮手」（2026-09-10 由「统计智慧助手」更名）：**默认底部居中**的椭圆胶囊悬浮入口 + 悬浮聊天窗，对接 OpenAI 兼容大模型接口，SSE 流式输出；会话与消息后端落库（按用户隔离），顶栏聊天按钮继续可用（同一入口）。

> **需求来源（留痕）**：2026-09-10 对话需求——原框架「Art Bot」演示聊天窗（ElDrawer 抽屉 + 本地模拟消息）改名为「统计智慧助手」，抽屉改为悬浮聊天窗，入口替代 dev 模式 Vue DevTools 悬浮按钮（删除 `vite.config.ts` 中 `vueDevTools` 插件，用户已确认），并本期对接真实 AI 接口（OpenAI 兼容 + SSE 流式 + 后端落库，用户已确认）。原框架组件 `art-chat-window` 保留不删、全局组件配置中停用。
>
> **追加需求（留痕）**：2026-09-10 对话需求——悬浮胶囊**支持鼠标随意拖动**（视口内夹取、窗口缩放回夹、位移小于阈值视为点击），聊天窗跟随胶囊位置弹出；胶囊颜色跟随系统主题色（`bg-theme` 链路 `--el-color-primary → --main-color → --theme-color`）。**缺陷修复（留痕）**：聊天窗打开后无法关闭——根因 `ArtSvgIcon` 组件 `inheritAttrs: false` 且仅透传 class/style，`@click` 事件未绑定到图标；关闭/新建对话图标改用 `ElIcon` + element-plus 图标。
>
> **追加需求（留痕）**：2026-09-10 对话需求——**入口唯一化**：只保留椭圆胶囊悬浮入口，移除右上角工具条的智能助手（聊天）入口（`headerBar.ts` `chat.enabled: false`，框架层顶栏文件未改）。

### 1.2 边界

- 本期**不含**：会话删除、多会话切换列表、附件/图片发送、流式中断重连。
- 模型供应商不锁定：OpenAI 兼容接口，`app.ai.*` 环境变量配置。
- 仅登录用户可见可用（走统一 `Authorization` 鉴权）。

## 3. 数据契约

| 字段       | 类型   | 必填 | 说明                                        |
| ---------- | ------ | :--: | ------------------------------------------- |
| session.id | number |  √  | 会话主键（自增）                            |
| session.userId | number | √ | 所属用户（隔离）                          |
| session.title | string | √  | 会话标题（首条用户消息前 20 字，默认「新的对话」） |
| message.id | number | √ | 消息主键（自增）                          |
| message.sessionId | number | √ | 所属会话                                |
| message.role | string | √ | user=用户提问 / assistant=AI 回答          |
| message.content | string | √ | 消息内容                                  |
| message.createTime | string | √ | 发送时间（yyyy-MM-dd HH:mm:ss）           |

> 实体字段全量定义见 `02-数据模型.md` 3.6 节。

| FR-AI-005  | 会话管理（最小集）：打开时自动取最近会话（无则新建）；「新建对话」按钮开新会话                                                          |   P1   |
| FR-AI-006  | 入口唯一化：仅保留椭圆胶囊悬浮入口；右上角工具条的智能助手（聊天）按钮移除（`config/modules/headerBar.ts` 的 `chat.enabled: false`）                                                                 |   P0   |
| FR-AI-007  | 未配置模型密钥 / 上游失败时：面板显示离线状态，SSE 返回 `{"error": "..."}` 事件，前端消息条提示                                          |   P0   |
| FR-AI-008  | 删除 `vite.config.ts` 中 `vueDevTools()` 插件（dev 悬浮按钮移除，用户已确认）；Vue DevTools 调试能力随之下线                            |   P0   |

## 5. 接口清单

| 方法 | 路径                              | 说明                                             | 所需权限点 |
| ---- | --------------------------------- | ------------------------------------------------ | ---------- |
| GET  | `/api/chat/sessions`              | 当前用户会话列表（最近更新在前）                 | 登录即可   |
| POST | `/api/chat/sessions`              | 新建会话，返回会话 id                            | 登录即可   |
| GET  | `/api/chat/sessions/{id}/messages` | 会话消息列表（时间正序，按用户隔离）            | 登录即可   |
| POST | `/api/chat/sessions/{id}/stream`  | SSE 流式对话：`{content}` → 逐段 `data:{"content"}`，结束 `data:[DONE]` | 登录即可   |

> 本期登录用户全员可用，不设权限点（权限引擎判定项见 `02-数据模型.md` 第 4 节，此处未新增 perm_key）。
