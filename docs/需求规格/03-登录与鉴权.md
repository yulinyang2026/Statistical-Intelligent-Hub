# 03 登录与鉴权

## 1. 模块定位

### 1.1 职责

账号登录、会话（JWT）签发与校验、角色上下文切换、退出登录、登录失败审计。

### 1.2 边界

- 不负责角色权限的**配置**（见 `13-角色与权限.md`）。
- 不负责用户账号的增删改（见 `12-用户与组织.md`）。

## 2. 依赖关系

| 方向     | 对象                                                        |
| -------- | ----------------------------------------------------------- |
| 依赖     | `02-数据模型`（User / Role / Log）                          |
| 被依赖   | **全部模块**（所有接口均需 `requireAuth` 中间件）           |
| 数据实体 | User、Role、Log                                             |

## 3. 数据契约

| 字段        | 说明                                                       |
| ----------- | ---------------------------------------------------------- |
| `account`   | 登录账号，唯一                                             |
| `password`  | 演示态任意密码可登录；正式版需加密校验                     |
| `status`    | 在职 / 停用；停用账号不允许登录                            |
| `role`      | 用户所属角色 key，决定权限点与数据范围                     |
| `token`     | JWT，含 `userId`，有效期由服务端配置；请求头 `Bearer` 携带 |

## 5. 接口清单

| 方法 | 路径           | 说明                                                   | 所需权限点 |
| ---- | -------------- | ------------------------------------------------------ | ---------- |
| POST | `/api/login`   | 账号密码登录，返回 `{ token, user }`；失败写日志        | 无         |
| GET  | `/api/me`      | 获取当前登录用户（含 `role`、`roleName`、`perms[]`）    | 已登录     |
| POST | `/api/switch`  | 演示态切换角色视角，返回新 token                        | 已登录     |
| POST | `/api/logout`  | 退出登录，写操作日志                                    | 已登录     |
| GET  | `/api/roles`   | 角色定义列表（登录页快速登录卡片、顶栏切换菜单用）      | 无         |

> `perms[]` 为当前用户权限点集合，前端据此渲染菜单与按钮。

## 6. 权限要求

| 角色       | 登录 | 切换角色（演示态） | 退出 |
| ---------- | :--: | :----------------: | :--: |
| 全部角色   |  √  |         √         |  √  |
| 停用账号   |  ×  |         ×         |  —  |

## 7. 验收标准

- [ ] 使用演示账号（如 `cuixq`）可登录，任意密码通过
- [ ] 账号不存在、已停用时提示明确且拒绝登录，并写入操作日志
- [ ] 登录后菜单按角色渲染，无权限菜单不出现
- [ ] 直接访问带参路由（如 `#/projects/pr1?tab=progress`），登录后直达该页
- [ ] 顶栏切换角色后，菜单与列表数据范围随之变化
- [ ] 退出后 token 失效，访问接口返回未登录
- [ ] 登录页有入场过渡动画
