# 07 项目管理与子系统

## 1. 模块定位

### 1.1 职责

管理**真实项目**全生命周期：列表（树形含子系统）、筛选、增删改、导入导出、详情页、子系统维护、待办任务数；项目可挂靠模块或专题。

### 1.2 边界

- 项目**状态由人工维护，不自动流转**（与模块/专题不同）。
- 子系统为项目下级，在列表中以树形展示，具备同等操作能力（可新增任务等）。
- 不负责任务本身的管理（见 `08-任务管理.md`）。

## 7. 验收标准

- [ ] 列表以树形展示「项目 → 子系统」，子系统缩进呈现
- [ ] 列表页有独立的「新增子系统」按钮，与「新增项目」并列
- [ ] 子系统行可新增任务、查看详情，与主项目能力一致
- [ ] 子系统显示任务数与待办数
- [ ] 项目状态不随任务变化而自动改变（人工维护）
- [ ] 删除项目时确认框明示子系统数、任务数、文档数
- [ ] 项目待办数字 = **未挂子系统的直属任务**中状态≠已完成的数量；子系统待办数 = 各自任务数；两者独立
- [ ] 子系统新增/编辑弹窗为**两列**布局，且**不出现**「成本对象」字段
- [ ] 归属产品从字典选择，停用项不可选
- [ ] 列表无横向滚动条
