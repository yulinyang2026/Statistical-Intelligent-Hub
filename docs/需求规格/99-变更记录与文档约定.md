| 缺陷修复（不改需求口径，如接口路径错误、鉴权失效、样式错位） |   不动    |   不动   | 追加一行，标注「缺陷修复（无需求变更）」 |  递增  |

### 3.2 版本号规则

- 小改动（**含缺陷修复**）递增次版本号：V6.0 → V6.1。
- 大范围结构性调整递增主版本号：V6.x → V7.0。
- 不引入三级修订号。

### 3.3 技术方案设计文档

`技术方案设计文档.md` 仅在**技术选型、架构分层、存储或部署方案变更**时同步；日常功能改动与缺陷修复不更新。

### 3.4 需求探询

- 存在歧义、多种合理理解，或影响结构/口径/交互的决策点时，先以问答形式（给出候选项与推荐项）确认后再实施，**不猜测**。
- 优先探询：术语与业务口径、范围边界（做/不做）、交互方式、权限差异、数据结构。
- 例外：改文案、改样式、明确指出的 bug 可直接执行。
- 每轮问答形成的结论须落入文档。
- 用户提出的每一条需求（含未定稿）须先登记 `16-待确认与非需求项.md` 第 2 节「对话需求登记」，定稿后归位对应模块文件并留痕。

### 3.5 模块化目录维护约定（本目录专用）

| 规则     | 说明                                                                                             |
| -------- | ------------------------------------------------------------------------------------------------ |
| 单一来源 | 本目录为 AI 开发依据；`docs/需求规格/需求规格说明书_V6.0.md` 为**人读合订本**，两者冲突时以本目录为准并回补合订本 |
| 归位原则 | 新增需求写入**对应模块文件**，禁止新建按版本号命名的补丁章节                                     |
| 数据优先 | 任何字段/枚举/权限点变更，**必须先改 `02-数据模型.md`**，再改模块文件                             |
| 下线处理 | 功能下线时从模块文件删除或标注「已下线」，并在 `16-待确认与非需求项.md` 记录移除版本               |
| 依赖同步 | 新增模块或改变依赖关系时，同步更新 `00-索引与开发指南.md` 的模块清单与依赖图                       |
| 文件头   | 每个模块文件的 YAML 头（`module` / `status` / `depends_on` / `data_entities` / `perm_keys`）须保持最新 |

### 3.6 需求登记与留痕约定（2026-09-09 起强制）

用户每次提出的需求与每次改动，按下表流程执行，**未同步文档视为任务未完成**：

| 步骤 | 动作 |
| ---- | ---- |
| 1. 登记 | 用户每次提出的需求/改动意向，先在 `16-待确认与非需求项.md` 第 2 节登记一行（日期/描述/状态），**未登记不得实施** |
| 2. 定稿 | 需求确认定稿后：涉及字段/枚举**先改 `02-数据模型.md`**，再写入对应模块文件，并在条目内留痕（提出时间/来源/结论） |
| 3. 归档 | 登记表「归位结果」列注明去处（模块文件 / FR 编号 / 版本），然后删除该登记行 |
| 4. 版本 | 每次改动在本文件第 2 节版本记录追加一行并递增版本号（缺陷修复同样递增） |

例外：纯缺陷修复（不改需求口径）跳过 1~3，直接执行第 4 步。

## 4. 全局技术约定速查

| 约定           | 说明                                                                                       |
| -------------- | ------------------------------------------------------------------------------------------ |
| 接口前缀       | 全部 `/api`，RESTful，JSON                                                                 |
| 鉴权           | `Authorization: Bearer <token>`；导出类接口额外支持 `?token=` 与 `x-token`                  |
| 权限判定       | 服务端按权限点判定，禁止硬编码角色名                                                       |
| 分页           | 默认 50 条/页，可选 50/100/150，分页固定页面右下角，返回 `{ list, total }`                  |
| 模块路径       | 模块/专题用**复数** `/api/modules`、`/api/topics`                                           |
| 依赖锁定       | `vue-router` 精确 `4.5.1`，禁止 `^`（规避 Edge 无法最小化缺陷）                             |
| 状态自动流转   | 仅模块/专题（待办>0→活跃，=0→非活跃）；项目状态人工维护                                    |
| 待办口径       | 状态 ≠ 已完成；模块/专题**仅统计直属任务**（挂靠概念 2026-09-11 移除）；**项目 = 未挂子系统的直属任务，子系统各计自己的，两者独立**，所有统计口径必须一致 |
| 数据仓储       | 当前为 JSON 文件（原型阶段），生产环境需替换为数据库，详见 `技术方案设计文档.md`             |
