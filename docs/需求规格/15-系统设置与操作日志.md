# 15 系统设置与操作日志

本文件包含两个相对独立的子模块：**15.1 系统设置（主题）**、**15.2 操作日志**。

---

## 15.1 系统设置（主题）

### 1. 模块定位

**职责**：主题配色与菜单布局/风格配置，后端持久化，全员生效。
**边界**：只负责视觉配置，不涉及业务数据。

### 2. 依赖关系

| 方向     | 对象                                              |
| -------- | ------------------------------------------------- |
| 依赖     | `02-数据模型`（Settings 实体）                    |
| 被依赖   | **全局 UI**（布局、菜单、配色由本模块配置驱动）    |
| 数据实体 | Settings                                          |

### 3. 数据契约

| 字段        | 类型   | 说明                                                    |
| ----------- | ------ | ------------------------------------------------------- |
| `primary`   | string | 主题色（7 预设：默认蓝/紫/青/绿/橙/红/灰 + 自定义取色） |
| `menuBg`    | string | 菜单背景色                                              |
| `menuLayout`| string | 菜单布局 `left` 左侧 / `top` 顶部                        |
| `menuStyle` | string | 菜单风格 `light` 亮色 / `dark` 暗色                      |
| `navBg`     | string | 导航栏背景色                                            |
| `topBg`     | string | 页面顶部颜色                                            |

### 4. 功能需求

| 编号      | 需求描述                                                                                                                                                                     | 优先级 |
| --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :----: |
| FR-V5-005 | **主题配置**：顶栏「系统设置」面板可配置 主题风格 / 菜单布局 / 菜单风格 / 系统主题色 / 盒子样式 / 容器宽度 / 基础配置等。**2026-09-11 修订（用户需求）**：设置**按用户存库**（不再是浏览器 localStorage 单机存储，也不再是「全员生效」）——每个用户可自定义自己的风格，换浏览器/换电脑登录后依然生效。**同日再修订（用户需求）**：**表格组件设置**（表格工具栏「设置」内的 斑马纹 / 边框 / 表头背景）**默认值改为「斑马纹 + 表头背景勾选、边框不勾选」**，且这三项**同样按用户存库**（随 UserSetting 同步；存量设置行缺这三键时按代码默认初始化，用户改选后以本人选择为准） |   P1   |
| FR-V5-024 | **主题体系**：提供 **7 套预设主色** + 自定义取色；支持**菜单布局**（左侧/顶部）与**菜单风格**（亮色/暗色）；**移除亮/暗主题切换按钮，默认亮色**                                |   P1   |

> 已知边界：主题色通过覆盖 Arco 的 `--primary-6` / `--arcoblue-6` 实现，属**近似覆盖**——主按钮、链接、选中态会跟随，部分组件次级色可能不完全一致；需要像素级全组件跟随需引入 Arco 运行时主题方案。菜单布局切换后需刷新页面生效。

### 5. 接口清单

| 方法 | 路径            | 说明                             | 所需权限点   |
| ---- | --------------- | -------------------------------- | ------------ |
| GET  | `/api/user/settings` | 读取**本人**界面设置（未保存过返回 `{}`） | 已登录 |
| PUT  | `/api/user/settings` | 保存**本人**界面设置（整份覆盖）          | 已登录 |

### 6. 权限要求

| 角色       | 查看 | 配置 |
| ---------- | :--: | :--: |
| 系统管理员 |  √  |  √  |
| 其他角色   |  —  |  —  |

### 7. 验收标准

- [ ] 顶栏**无**亮/暗主题切换按钮，默认亮色
- [ ] 系统设置页可修改主题色，保存后全局生效
- [ ] 7 套预设主色可一键切换，支持自定义取色
- [ ] 菜单布局可切换左侧/顶部（切换后刷新生效）
- [ ] 菜单风格可切换亮色/暗色
- [ ] 导航栏背景色、页面顶部颜色可分别配置
- [ ] 配置持久化到服务端（**按用户**），换浏览器登录仍是自己的风格；换用户互不影响

## 15.2 操作日志

### 1. 模块定位

**职责**：关键操作留痕与查询。属**横切关注点**，所有模块的写操作均需调用。
**边界**：只记录与展示，不参与业务。

### 2. 依赖关系

| 方向     | 对象                                                  |
| -------- | ----------------------------------------------------- |
| 依赖     | `02-数据模型`（Log 实体）                             |
| 被依赖   | **全部模块**（所有写操作调用 `addLog()`）             |
| 数据实体 | Log                                                   |

### 3. 数据契约

| 字段       | 说明                                    |
| ---------- | --------------------------------------- |
| time       | 操作时间                                |
| operator   | 操作人                                  |
| module     | 模块（徽标展示）                        |
| target     | 操作对象                                |
| action     | 动作                                    |
| detail     | 详情                                    |

### 4. 功能需求

| 编号       | 需求描述                                                                                                                                                                                 | 优先级 |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :----: |
| FR-LOG-001 | 记录关键操作：登录、**登录失败**、退出、角色切换、项目/模块/专题/任务/文档/用户的增删改、子系统维护、导入导出、成员分配/移除、基础数据变更、计划编排（拖拽/标记完成）、看板拖拽、模块/专题状态自动流转 |   P0   |
| FR-LOG-002 | 字段：时间、操作人、模块（徽标）、操作对象、动作、详情                                                                                                                                       |   P0   |
| FR-LOG-003 | **系统级操作日志页**（时间倒序、总数、分页默认 50），记录**所有人**的操作轨迹；支持 操作人/模块/动作/操作对象/详情/时间区间 筛选 + 表头漏斗。**2026-09-11 修订**：~~项目/模块/专题详情页内按对象过滤展示~~（详情页「操作日志」Tab 已去除，日志统一在系统级页面查看） |   P0   |
| FR-LOG-004 | 权限：**仅系统管理员可查看**（权限点 `log:view` 仅绑 R_SUPER；2026-09-11 由「管理员/部门经理/组长」收紧，用户需求）；菜单入口在「系统配置」分组                                                                                                                           |   P0   |
| FR-V5-007  | 补充遗漏操作类型：登录失败（账号不存在/已停用）等                                                                                                                                             |   P1   |

### 5. 接口清单

| 方法 | 路径         | 说明                       | 所需权限点 |
| ---- | ------------ | -------------------------- | ---------- |
| GET  | `/api/system/log/page`  | 操作日志列表（时间倒序、分页、筛选 + filters） | `log:view`（仅 R_SUPER） |

> 写入由各模块通过 `addLog(module, target, action, detail, operator)` 调用，无独立接口。

### 6. 权限要求

| 角色       | 查看日志 |
| ---------- | :------: |
| 系统管理员 |    √    |
| 部门经理   |    —    |
| 组长       |    —    |
| 组员       |    —    |
| 只读查看者 |    —    |

### 7. 验收标准

- [ ] 登录、登录失败、退出、角色切换均有记录
- [ ] 各模块增删改、导入导出、成员变更、拖拽、状态自动流转均有记录
- [ ] 全局日志页按时间倒序展示，显示总数
- [x] ~~对象详情页日志 Tab~~（2026-09-11 已按需求去掉，改为系统级日志页）
- [ ] 日志含操作人、模块、对象、动作、详情五要素
- [ ] 非系统管理员访问日志接口返回 403（菜单为前端静态菜单，非管理员可见但接口拦截）

> **实施留痕（2026-09-11，操作日志页面落地，用户需求 V6.41）**：系统级操作日志页面落地（原「展示页留待该模块落地」）——后端新增 `GET /api/system/log/page`（分页 + 操作人/模块/动作/关键字/时间区间 + 通用 filters，权限点 `log:view` 仅 R_SUPER）；前端新增 `views/log/`（表头漏斗全字段筛选、分页默认 50/可选 50-100-150、固定右下角）、路由与菜单「系统配置 → 操作日志」、zh/en 文案；记录**所有人**的操作轨迹；模块详情与项目详情的「操作日志」Tab 同步去除。

> **实施留痕（2026-09-11，V6.54，用户需求）**：① **系统设置按用户存库**——后端新增实体 `UserSetting{userId, payload}`（落 `data/system/user-setting.json`）与 `GET/PUT /api/user/settings`（只读写当前登录用户自己的设置，无需额外权限点）；前端新增 `hooks/useUserSettings.ts`，在应用根组件 `App.vue` 挂载：启动/登录后拉取本人设置并应用，之后任一设置项变更**防抖 800ms 回写**服务端；同步范围为 setting store 的全部外观/偏好键（主题风格/菜单布局/菜单风格/系统主题色/盒子样式/容器宽度/基础配置等 25 项）。**删除用户时一并删除其界面设置**（否则主键复用可能串到新用户）。
> ② **「显示功能页签」配置加回基础配置**（V6.10 精简时被移除），并**默认不展示**（`config/setting.ts` 的 `showWorkTab=false`）；文案由「开启多标签栏」改为「显示功能页签」。
> ③ **去掉基础配置里的「显示顶部进度条」**配置项。
> ④ **菜单风格只保留第一个默认项**，第二个（暗色）从 `config/index.ts` 的 `themeList` 删除——面板内只剩 1 项、**无第二项可选**（该项即当前值，点击为无操作，效果等同不可选择；顶部/双列菜单与暗色模式下的原有禁用光标逻辑未改动）。
> ⑤ **涉及的禁改目录文件（用户明确要求，已告知）**：`components/core/layouts/art-settings-panel/composables/useSettingsConfig.ts`（加回功能页签项、去掉进度条项）、`.../widget/MenuStyleSettings.vue`（菜单风格置为不可选）；另 `config/setting.ts`、`config/index.ts`、`App.vue` 不在禁改清单内。
> ⑥ **实测**：设置接口读写与**用户隔离**通过（另建用户读写互不影响，管理员设置不被覆盖）；无头浏览器核对——「功能页签」默认不出现、设置面板基础配置含「显示功能页签」且不含「显示顶部进度条」、菜单风格只剩 1 个选项、批量删除按钮位于工具条末尾且同行。`e2e-test.py` **243/243 通过**（新增 10 项设置用例：读→写→回读→用户隔离→**快照还原**；用例自带快照/还原，跑完管理员真实偏好零差异）；`pnpm build` 与 `gradlew compileJava` 0 错误。
> ⑦ **保护性收尾**：`post-e2e-cleanup.py` 与 `clear-mock-data.py` 增加 `user-setting.json` 清理——用户被删除时一并移除其设置行，作为 ① 中「主键复用可能串到新用户」风险在**脚本侧的兜底**（此前两脚本按行删用户却留下其设置行）。

> **实施留痕（2026-09-11，V6.55，用户需求）**：**表格组件设置默认值 + 按用户同步**——表格工具栏「设置」内的 斑马纹 / 边框 / 表头背景 三项：① **默认值改为 斑马纹开、表头背景开、边框关**（`store/modules/table.ts` 初始值，**禁改目录文件，用户已确认**；边框本就是关）；② 三键纳入**用户级设置同步**（`hooks/useUserSettings.ts` 新增 table store 同步段，与本文件 ① 的 25 个 setting 键合并为同一份 payload 存 `UserSetting`，仍防抖 800ms 回写）；③ **存量设置行缺这三键**时按代码默认初始化（`TABLE_DEFAULTS`），否则浏览器 localStorage 里的旧值会一直生效、默认值改动永远看不到；此机制与 `store/modules/table.ts` 的初始值需保持一致（两处注释互指）。**实测**：全新浏览器配置登录后——列表带 `el-table--striped`、无 `el-table--border`、表头背景为 `--el-fill-color-lighter`，三项均符合新默认。
