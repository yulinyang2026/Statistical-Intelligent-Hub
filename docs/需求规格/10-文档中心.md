# 10 文档中心

## 1. 模块定位

### 1.1 职责

Markdown 文档的全局中心（跨对象检索）与对象内文档 Tab；编辑、预览、删除、字数统计。

### 1.2 边界

- 文档必须归属模块/专题/项目之一（三选一）。
- 本期**不含物理附件**（正式版再引入对象存储）。

## 2. 依赖关系

| 方向     | 对象                                                          |
| -------- | ------------------------------------------------------------- |
| 依赖     | `05-模块管理`、`06-专题管理`、`07-项目管理与子系统`            |
| 被依赖   | 各对象详情页「文档附件」Tab                                   |
| 数据实体 | Doc                                                           |

## 3. 数据契约

| 字段       | 类型   | 必填 | 说明                                    |
| ---------- | ------ | :--: | --------------------------------------- |
| id         | string |  —   | 主键，前缀 `doc`                        |
| title      | string |  √  | 文档标题                                |
| projectId  | string |  —   | 归属项目（三选一）                      |
| moduleId   | string |  —   | 归属模块                                |
| topicId    | string |  —   | 归属专题                                |
| content    | string |  —   | 正文（Markdown）                        |
| updatedBy  | string |  —   | 更新人                                  |
| updatedAt  | string |  —   | 更新时间                                |
| wordCount  | number |  —   | 字数                                    |

## 5. 接口清单

| 方法   | 路径             | 说明                       | 所需权限点 |
| ------ | ---------------- | -------------------------- | ---------- |
| GET    | `/api/docs`      | 列表，支持标题检索与分页   | `doc.view` |
| GET    | `/api/docs/:id`  | 详情（含 `canEdit`、`canDelete`） | `doc.view` |
| POST   | `/api/docs`      | 新增                       | `doc.edit` |
| PUT    | `/api/docs/:id`  | 编辑                       | `doc.edit` |
| DELETE | `/api/docs/:id`  | 删除（二次确认）           | `doc.delete` |

## 7. 验收标准

- [ ] 全局文档中心可按标题跨对象检索
- [ ] 对象详情页「文档附件」Tab 只显示该对象的文档
- [ ] Markdown 编辑器工具栏功能全部生效（加粗/标题/列表/表格/代码块/链接等）
- [ ] 保存后自动进入预览模式，记录更新人与时间
- [ ] 新建时未选归属无法保存
- [ ] 删除需二次确认
- [ ] 只读角色以「只读预览」标识查看，无编辑入口
