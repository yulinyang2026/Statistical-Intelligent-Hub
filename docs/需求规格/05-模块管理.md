# 05 模块管理

## 1. 模块定位

### 1.1 职责

管理**可持续交付的功能模块**全生命周期：列表、筛选、增删改、导入导出、详情页（进度看板 / 成员 / 文档 / 日志）、待办任务数、状态自动流转。

### 1.2 边界

- 专题管理为**独立模块**（见 `06-专题管理.md`），但共用同一套交互与状态字典。
- 模块可被项目挂靠（见 `07-项目管理与子系统.md`）。
- 模块分类与归属产品由基础数据字典提供，本模块不维护字典本身。

## 5. 接口清单

| 方法   | 路径                                | 说明                                       | 所需权限点  |
| ------ | ----------------------------------- | ------------------------------------------ | ----------- |
| GET    | `/api/modules`                      | 列表，支持 `kw/product/category/dept/team/owner/status/scope/page/size` | `module.view` |
| GET    | `/api/modules/:id`                  | 详情（含统计概览、挂靠项目、成员）          | `module.view` |
| POST   | `/api/modules`                      | 新增                                       | `module.edit` |
| PUT    | `/api/modules/:id`                  | 编辑                                       | `module.edit` |
| DELETE | `/api/modules/:id`                  | 删除（级联提示任务数）                      | `module.edit` |
| GET    | `/api/export/modules`               | 导出 Excel(.xlsx)（支持 `?token=`）          | `module.view` |
| POST   | `/api/import/modules`               | 导入 Excel(.xlsx)                           | `module.edit` |

> 路径**统一用复数** `/api/modules`（后端同时兼容单数 `/api/module`，勿改回单数）。
> 补充（2026-09-10 实现）：列表/详情均带 `GET /api/modules/options`（产品/分类/状态字典 + 部门/小组组织树 + 现有负责人候选值）；`scope=mine` 表示仅本人负责的模块；`size=0` 表示全量（导出复用）。

## 7. 验收标准

- [ ] 列表无横向滚动条，列宽自适应
- [ ] 筛选条件变更即自动查询，无「查询」按钮，有「重置」
- [ ] 新增时归属产品、模块分类从字典读取，停用项不可选
- [ ] 列表「待办任务」为醒目数字，点击跳转到详情进度看板
- [ ] 待办数字 = 详情页看板中未完成任务数（含挂靠项目任务）
- [ ] 模块无待办时状态自动变「非活跃」，有待办时自动变「活跃」
- [ ] 删除有任务的模块时，确认框明示将删除的任务数
- [ ] 导出为 .xlsx，Excel/WPS 打开中文不乱码
