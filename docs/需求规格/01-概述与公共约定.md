# 01 概述与公共约定

## 1. 模块定位

### 1.1 职责

本文件是**所有模块共享的基础约定**，包含：项目背景与范围、术语表、角色与权限模型、界面交互框架、非功能需求。任何模块开发前都应先读本文件。

### 1.2 边界

- 不包含具体业务模块的字段与接口（见各模块文件）。
- 不包含数据实体定义（见 `02-数据模型.md`）。

## 2. 项目概述

### 2.1 建设背景

政府统计涉及多个产品线（部门统计、金融监管、统一报表、国资监管等），每个产品线又包含多个项目与模块/专题，信息分散在不同表格与文档中，存在查找困难、任务分配混乱、边界不清、进度不透明、责任人不明确、统计依赖人工等问题，需要统一平台承载。

### 2.2 建设目标

1. 模块、专题与项目**分层管理**：统一关注怎么做、谁来做、什么时候做完。
2. 对象**全生命周期信息统一维护**：基础信息、子系统、进度、成员、任务、文档、状态构成单一数据源。
3. **计划驱动执行**：周计划 + 任务池，计划与实际对照。
4. **权责清晰**：按组织架构分层授权，数据范围与操作权限分级。
5. **可审计**：关键操作留痕，支持追溯。

### 2.3 范围界定

| 范围         | 内容                                                                                                                                                       |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **本期范围** | 登录鉴权、数据看板、模块管理、专题管理、项目管理（含子系统）、任务管理、周计划管理、文档中心、对象内成员管理、系统管理（用户/组织/角色/基础数据/系统设置/操作日志）、界面交互框架 |
| **不在范围** | 全局成员管理页（V5.0 已移除）、月计划（V5.0 已移除）、移动端适配（待确认）、公网部署方案（待确认）                                                        |

### 2.4 术语表

| 术语                | 说明                                                                                        |
| ------------------- | ------------------------------------------------------------------------------------------- |
| 模块（Module）      | 可持续交付的功能模块，有独立版本与生命周期，如「国企名录」「移动端」；**2026-09-11 起可见性 = 参与者（模块负责人/研发负责人/测试负责人）及其所有上级**，系统管理员全量 |
| 专题（Topic）       | 阶段性特有事项，如「前端性能优化」                                                          |
| 项目（Project）     | 真实项目，有项目周期（起止日期）与预算，包含多个子系统；**2026-09-11 起不再有「挂靠模块/专题」概念**（表单、列表、详情、CSV 均已移除） |
| 子系统（Subsystem） | 项目的下级拆分单元，1 对多；列表中与项目树形展示，具备同等操作能力                          |
| 归属产品            | 基础数据字典：模块/项目归属的产品线                                                         |
| 模块分类            | 基础数据字典：模块的技术分类（BSP产品/组件/其他）                                           |
| 监督链              | 组织架构上下级：系统管理员→部门经理→组长→组员；**「权限人员」= 本人 + 监督子树内全部人员** |
| 组织架构树          | **部门 → 小组 → 成员**三级，用于组织展示；监督链仍由「直属上级」构成，两者互不替代          |
| 待办任务            | 状态 ≠ 已完成的任务（待处理/进行中/受阻均计入）                                             |
| 我的待办            | **近三天**内需完成、且分配给当前用户的任务（判定规则见 `04-数据看板.md`）                   |
| 计划完成日期        | 任务字段 `planDate`（YYYY-MM-DD），由周计划拖拽写回，可空                                   |
| 任务池              | 周计划待编排集合：**截止月份 = 当前查看周所在月**的全部任务（含已完成，置灰不可拖）         |
| 干系人              | 参与项目/模块/专题但不是主责人                                                              |
| RBAC                | 基于角色的访问控制                                                                          |
