## 1. 模块定位

### 1.1 职责

系统核心。负责任务的列表（树形）、筛选、增删改、双视图（列表/看板）、看板分组与拖拽、子任务、时间字段（截止月份 / 计划完成周 / 计划完成日期）、待办口径与状态自动流转触发。

### 1.2 边界

- 任务**归属**模块/专题/项目之一，**可为空**（计划外临时任务）。
- 任务层级**仅两级**，子任务下不能再建子任务。
- 周计划的编排与写回见 `09-周计划管理.md`（本模块提供任务数据与被写回的 `planDate` 字段）。
- 看板的「年月过滤」按**计划完成时间所属月份**过滤（2026-09-09 起）。

| GET    | `/api/tasks/options`  | 筛选候选值（belongOptions、deadlines、statuses、priorities、assignees、groups、subsystems） | `task.view` |
| POST   | `/api/tasks`          | 新增（可无归属；子任务继承父任务归属与子系统）                        | `task.create` |
| PUT    | `/api/tasks/:id`      | 编辑（含子任务环检测、层级限制校验）                                  | `task.edit` |
| PATCH  | `/api/tasks/:id`      | **单字段更新**，供看板拖拽与工时双击编辑：`{ field, value }`，field 支持 `status/priority/assignee/group/deadline/planDate/hours`；服务端校验 `task.edit`（无 `task.view-all` 时仅限分配给自己，403），值未变化返回 `{ changed: false }`（不写库不写日志），变更时**写操作日志（旧值→新值）**并触发模块/专题状态自动流转 | `task.edit` |
| DELETE | `/api/tasks/:id`      | 删除（级联删除子任务，返回 `cascaded` 数量）                          | `task.delete` |
| GET    | `/api/export/tasks`   | 导出 Excel(.xlsx)（功能待实现，口径由 CSV 改为 Excel，见 V6.50）      | `task.view` |
| POST   | `/api/import/tasks`   | 导入 Excel(.xlsx)（功能待实现）                                       | `task.edit` |

> **模块/专题任务范围**：`GET /api/tasks?moduleId=m1` 返回「直属任务 ∪ 挂靠该模块的项目任务」，与列表待办数同源。

## 6. 权限要求

> 按权限点判定（禁止硬编码角色名）：查看范围由 `task.view-all` 决定（无 → 仅 assignee = 自己的任务）；编辑由 `task.edit` 决定（无 `task.view-all` 时仅限分配给自己的任务）；只读 = 无 `task.edit`（可看全部但无编辑入口，页面顶部只读提示条）。

| 角色       | 查看             | 新增/删除        | 编辑                      | 权限点映射（2026-09-10 起）                |
| ---------- | ---------------- | ---------------- | ------------------------- | ----------------------------------------- |
| 系统管理员 | 全部             | √                | √                         | view + view-all + create + edit + delete  |
| 部门经理   | 权限范围内       | √（范围内）      | √（范围内）               | view + view-all + create + edit（现简化档）|
| 组长       | 权限范围内       | √（范围内）      | √（范围内）               | view + view-all + create + edit（现简化档）|
| 组员       | 仅自己的         | √（仅自己的）    | √（**仅限分配给自己的**） | view + create + edit（**无 view-all**）    |
| 只读查看者 | 全部（只读）     | —                | —                         | view + view-all（**无 create/edit**）      |

> 说明（2026-09-10）：经理/组长「本人+下属」的组织范围档位暂以 `task.view-all` 全量简化替代，待数据范围引擎（角色 dataScope）落地后收紧。
