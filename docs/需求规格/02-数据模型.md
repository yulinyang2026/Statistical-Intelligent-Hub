# 02 数据模型

> **本文件是数据管理专项**，所有模块的字段定义、枚举取值、权限点均以此为准。
> 修改任何实体字段，必须同步本文件。

## 1. 模块定位

### 1.1 职责

- 定义系统全部**实体、字段、关系**。
- 定义全部**枚举字典**及其维护方式。
- 定义全部**权限点**（权限引擎判定依据）。

### 1.2 边界

- 不包含接口定义（见各模块文件第 5 节）。
- 不包含 UI 呈现（见各模块文件第 4 节）。

## 2. 实体关系

```
模块 Module  1 ──── N 任务 Task
专题 Topic   1 ──── N 任务 Task
项目 Project 1 ──── N 任务 Task
项目 Project 1 ──── N 子系统 Subsystem   （子系统 1 ──── N 任务，可选关联）

项目 Project N ──── 1 模块/专题（项目挂靠：belongType + belongId）

任务 Task、文档 Doc 均归属三者之一（项目/模块/专题）；任务归属可为空（计划外临时任务）

用户 User（自引用：supervisorId 直属上级，构成监督链：组员→组长→部门经理→系统管理员）
部门 Department 1 ──── N 小组 Group 1 ──── N 用户 User（组织架构展示结构）

计划项 PlanItem N ──── 1 任务 Task（周计划的计划与实际记录）

基础数据类型 DictType 1 ──── N 基础数据字典项 BaseDictItem（被模块/项目引用）
操作日志 Log（弱关联：记录模块 + 目标名称，不参与主业务）
```

**关键约束**

- 任务**归属三选一且必填**（2026-09-11 用户需求收紧）：`projectId` / `moduleId` / `topicId` 至多一个非空，**新增时至少有一个**（原先允许全空 = 计划外临时任务，现不再允许）；子任务继承父任务归属。**归属小组同样必填**，候选取自组织管理的组织名称。
- 任务层级**仅两级**：子任务不能再创建子任务。
- **模块/专题的任务范围 = 直属任务**（挂靠概念 2026-09-11 起彻底移除，FR-V5-014 相应修订）。
- **项目与子系统的任务范围相互独立**（2026-09-11 新增）：项目统计只算**未挂子系统的直属任务**，子系统各算自己的，两者不重复计数。
- 组织架构树（部门→小组→成员）**仅用于展示**；权限与数据范围仍由 `supervisorId` 监督链决定。

## 3. 实体字段

### 3.1 业务对象

| 实体                | 字段                                                                                                                                                                             |
| ------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **模块 Module**     | id、名称、**归属产品（字典引用）**、**分类（字典引用 moduleCategory）**、负责部门、负责小组、模块负责人、研发负责人（多）、测试负责人、成本对象、状态（字典引用：模块/专题状态）、干系人、描述 |
| **专题 Topic**      | id、名称、负责部门、负责小组、专题负责人、研发负责人（多）、测试负责人、成本对象、状态（字典引用：模块/专题状态）、干系人、描述                                                    |
| **项目 Project**    | id、名称、成本对象、重要级别、**归属产品（字典引用）**、所属产品型谱、负责部门、负责小组、销售负责人、项目经理、项目负责人、研发负责人、测试负责人、**项目状态（字典引用，人工维护）**、预算、开始/结束日期（表单合并为「项目周期」区间录入）、干系人、描述。**2026-09-11 起挂靠对象（belongType/belongId）概念移除**（字段保留但不再写入与展示） |
| **子系统 Subsystem** | id、所属项目（projectId）、名称、负责人、排序；**2026-09-11 扩字段**：归属产品、负责部门、负责小组、研发负责人、项目经理、测试负责人、项目状态（与项目同口径，可由所属项目预填）；**同日再修订：成本对象字段下线**（表单与列表/详情列一并去掉，数据字段保留兼容，不覆盖存量值） |

> 专题**不设**「分类」「归属产品」字段，其余与模块一致（2026-09-11 主题实体 `Topic` 落地，替换原 `belong-topic` 垫底数据源；主键前缀 `tp`，内置 5 个专题）。

### 3.2 任务与计划

| 实体              | 字段                                                                                                                                                                                                                                |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **任务 Task**     | id、标题、说明、归属（projectId/moduleId/topicId 三选一，**新增时必选其一**）、执行人、优先级、**计划完成时间（planDate，YYYY-MM-DD，必填，2026-09-09 起合并原截止月份/计划完成周/计划完成日期）**、预计工时、状态（**含子任务时自动推导**：全完成=已完成，否则进行中）、归属小组、父任务（parentId，**仅两级**） |
| **计划项 PlanItem** | id、任务（taskId）、粒度（**当前仅使用「周」**）、周期键（如 `2026-W37`）、星期（1~7）、类型（计划/实际）、实际工时（hours，可空）、填写人、填写时间                                                                                |

### 3.3 文档与成员

| 实体        | 字段                                                                                        |
| ----------- | ------------------------------------------------------------------------------------------- |
| **文档 Doc** | id、标题、归属（projectId/moduleId/topicId 三选一）、内容（Markdown）、更新人、更新时间、字数 |

| **角色 Role**         | key（唯一）、名称、代表账号（rep，快速切换用）、数据范围（all 全部 / scope 本人+下属 / own 仅本人）、内置标记、权限点集合（perms）         |

### 3.6 AI 对话（管理小帮手，2026-09-10 新增）

| 实体                    | 字段                                                                                          |
| ----------------------- | --------------------------------------------------------------------------------------------- |

## 5.1 操作日志（2026-09-10 起任务写操作落库）

## 6. 跨模块数据一致性规则（重要）

| 规则         | 说明                                                                                                                                                  | 涉及模块            |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------- |
| **待办口径** | 待办 = 状态 ≠ 已完成；模块/专题**仅统计直属任务**（挂靠概念已移除）。列表列、详情看板、统计概览、数据看板分布图必须**同源同口径**                        | 05,06,07,08,04      |
| **状态流转** | 仅模块/专题自动流转（待办>0→活跃，=0→非活跃），**项目状态人工维护不流转**                                                                              | 05,06,07            |
| **任务范围** | 模块/专题详情看板、统计、列表待办数，均使用 `直属任务`；**项目统计 = 未挂子系统的直属任务，子系统统计 = 自身任务，两者独立不重复计数**                     | 05,06,07,08         |
| **删除级联** | 删除项目 → 级联删除子系统、任务、文档；删除任务 → 级联删除子任务；均需二次确认并明示数量                                                              | 07,08               |
| **字典引用** | 已被引用的字典项**不可物理删除，仅可停用**；停用后新建/编辑不可选，存量数据保留显示                                                                   | 14 → 05,06,07       |
| **人员字段** | 所有对象的人员字段（负责人、执行人等）存**姓名字符串**，与 `User.name` 关联（非 ID），用于权限人员过滤与成员推导                                        | 全部                |

## 7. 验收标准（数据层）

- [ ] 所有实体字段与本节表格一致，无缺失、无多余
