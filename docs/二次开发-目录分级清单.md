### 1.5 ⚠️ 三个"看起来像示例、实为框架"的坑

1. **`frontend/src/views/index/index.vue` 不是首页，是整站布局容器**（内含 Sidebar/HeaderBar/PageContent/GlobalComponent）。所有一级菜单的 `component: '/index/index'` 都指向它，**删了全站白屏**。
2. **`frontend/src/views/outside/Iframe.vue`** 是 iframe 内嵌能力页，被静态路由引用。
3. **`frontend/src/mock/json/chinaMap.json`** 被核心组件 `art-map-chart` 引用；**`frontend/src/mock/upgrade/changeLog.ts`** 被 `utils/sys/upgrade.ts` ← `App.vue` 引用。这两个在 `mock/` 下但**不是可删的假数据**（除非你同时改掉引用方）。

## 5. 二次开发推荐姿势

1. **新增业务页面**：`frontend/src/views/<你的模块>/index.vue`，配 `frontend/src/router/modules/<你的模块>.ts`，在 `modules/index.ts` 注册，文案加进 `locales/langs/*.json`
2. **接口**：`frontend/src/api/<业务>.ts` + `frontend/src/types/api/api.d.ts` 声明类型
3. **接自家后端**：改 `frontend/.env*` 的 `VITE_API_URL` / `VITE_API_PROXY_URL` + `frontend/src/utils/table/tableConfig.ts` 字段映射 + `frontend/src/utils/http` 的响应解包约定
4. **换皮**：改 `styles/core/tailwind.css` 变量 + `config/index.ts` 主色 + `images/common/logo.webp`
5. **升级框架时**：只有本清单第 1 节之外的文件冲突才需要你处理

## 6. 自检备注（核验时发现的反直觉点）

- `frontend/src/views/index/index.vue` 是**布局容器**不是首页，别删
- `frontend/vite.config.ts` 里的 `@icons` 别名指向 `frontend/src/assets/icons`，**该目录当前不存在**，图标走 Iconify（`utils/ui/iconify-loader.ts`）
- `frontend/src/mock/json/chinaMap.json`、`frontend/src/mock/upgrade/changeLog.ts` 虽在 `mock/` 下，但被核心组件/App.vue 引用
- 路由为 **hash 模式**（`createWebHashHistory`），部署到子目录改 `VITE_BASE_URL`
- 表格/表单类组件通过 `unplugin-vue-components` **自动注册**，不需要手动 import，也不要手动改 `components.d.ts`
